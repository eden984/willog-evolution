# 윌로그의 진화 — 30초 아이소메트릭 모션 그래픽

콜드체인 모니터링 Willog가 **기록(BLE·NFC) → 실시간(LTE·GPS) → 예측(AI, 개발 중)**으로 진화하는 이야기를 담은 30초 웹 모션 그래픽이야. 배경 음악도 들어 있어.

▶ **보러 가기:** https://eden984.github.io/willog-evolution/

## 보는 법
- 링크를 열고 **▶ 소리 켜고 재생**을 눌러.
- 휴대폰은 **가로로** 돌리면 크게 보여.
- 키보드: `Space` 재생/정지 · `R` 처음부터 · `M` 소리 · `H` 컨트롤 숨기기

## 장면 구성
| 시간 | 장면 |
|---|---|
| 0–4s | 도입: "지금 이 화물, 안전할까요?" |
| 4–12s | 01 기록하다: BLE·NFC 패시브. 기록은 정확하지만 확인은 도착 후에 가능 |
| 12–20s | 02 실시간으로 보다: LTE·GPS. 온도 상승 → 담당자 알림 → 기사 연락 → 정상 복귀 |
| 20–26s | 03 예측하다: AI(개발 중인 방향). 이탈 전에 미리 경고하는 게 목표 |
| 26–30s | 진화 요약 + 로고 |

## 파일
- `index.html`: 애니메이션 전체. 하나의 마스터 시계가 모든 움직임과 음악을 맞춰.
- `bgm.m4a`: 배경 음악. `tools/music.py`로 직접 작곡·합성해서 저작권 걱정이 없어.
- `thumb.jpg`: 링크 미리보기 이미지
- `tools/render.py`: 장면 캡처용 스크립트 (playwright 필요)

## 참고
- 로고는 임시 디자인이야. 화면 속 수치(예시)와 AI 기능(개발 중)은 연출용 예시야.
- 이 영상은 Claude가 만들었고, 다섯 명의 검토 에이전트(담화린·라미아·일리나·라피르·매유진)가 여러 번 검토하고 다듬었어.
